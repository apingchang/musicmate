## 1. 整體架構

### 視窗模型：單視窗 + 底部標籤導航

採用**單一主視窗**設計，底部以 Tab 導航切換三大核心功能（自動翻譜、節拍器、調音器）。理由如下：

- Windows 11 使用者已熟悉 Fluent Design 的底部導航慣例
- 練琴時需要快速切換工具，單視窗可減少注意力分散
- 未來跨平台（Android / iOS）時，底部 Tab 是最通用的移動模式
- 單視窗載入速度較快，Python GUI 啟動較重的情境下更為順暢

### 視窗基本屬性

| 屬性 | 設定 |
|------|------|
| 最小尺寸 | 800 × 600 px |
| 預設尺寸 | 1200 × 800 px |
| 可縮放 | 是（響應式佈局） |
| 標題列 | 標準 Windows 標題列（系統外觀） |
| 主題 | 跟隨 Windows 系統深色/淺色設定 |

## 3. 每個頁面 / 面板功能說明

### 3-1. 自動翻譜頁（Sheet Music Auto-Scroll）

**用途：** 顯示樂譜 PDF/圖片，自動向上滾動，充當虛擬樂譜架。

**子區塊：**

- **樂譜顯示區**（主區域）
  - 顯示目前載入的 PDF 或圖片樂譜
  - 支援滑鼠滾輪手動滾動
  - 雙擊樂譜：全螢幕模式

- **控制工具列**（樂譜顯示區正下方）
  - `開啟樂譜` 按鈕（開啟檔案對話框，支援 PDF / JPG / PNG）
  - 播放 / 暫停按鈕（控制自動滾動）
  - 速度滑桿（滾動速度：0.5x ~ 3.0x）
  - 當前頁 / 總頁數顯示
  - 上一頁 / 下一頁 按鈕

- **快捷鍵提示列**（底部小字）
  - `Space`：播放/暫停｜`← →`：上一頁/下一頁｜`F`：全螢幕

**特殊狀態：**
- 無樂譜時：顯示「點擊『開啟樂譜』或拖曳 PDF/圖片到這裡」引導區塊
- 支援拖放檔案

---

### 3-2. 節拍器頁（Metronome）

**用途：** 精準節拍器，協助練琴時維持穩定速度。

**子區塊：**

- **節拍顯示區**（畫面中心，大字體）
  - 目前 BPM 數字（超大字，視覺焦點）
  - 4/4、3/4、6/8 等拍號顯示（在 BPM 下方）
  - 當前拍點閃爍動畫（跟著節拍閃一下）

- **BPM 控制區**
  - 轉盤或滑桿（40 BPM ~ 240 BPM）
  - `-10 / -1 / +1 / +10` 微調按鈕
  - 常用 BPM 快捷：60、80、100、120 四個快速按鈕

- **拍號選擇器**
  - 下拉選單：2/4、3/4、4/4、5/4、6/8、7/8、12/8

- **節拍音效區**
  - 節拍器音色選擇：Click / Woodblock / Digital（三選一）
  - 音量滑桿

- **計時器（附帶功能）**
  - 設定練琴時長（5 / 10 / 15 / 30 / 45 / 60 分鐘）
  - 開始 / 停止按鈕
  - 倒數結束時提醒

- **發聲視覺化**
  - 節拍燈：跟著拍子亮燈/熄燈，加強視覺節奏感

---

### 3-3. 調音器頁（Tuner）

**用途：** 收音麥克風偵測音高，協助樂器對音。

**子區塊：**

- **指針 / 弧形顯示區**（主視覺）
  - 半圓弧形指針儀表
  - 顯示目前偵測到的音名（如：C / C# / D）
  - 指針偏左 = 偏低，指針偏右 = 偏高
  - 綠色區間（±5 cents）= 準確
  - 紅色 = 差太多需調整

- **Cents 數值顯示**
  - 數字顯示偏差值（如：-12 cents、+7 cents）

- **頻率顯示**
  - 目前音高的 Hz 頻率（如：440.0 Hz）

- **麥克風控制**
  - 麥克風圖示按鈕：點擊啟動/關閉收音
  - 收音時圖示發綠光
  - 下方顯示「麥克風已啟動」或「麥克風已停用」

- **參考音設定**
  - A4 頻率設定（預設 440 Hz，可調整 430~450）
  - 快捷：432 Hz / 440 Hz / 442 Hz 按鈕

- **支援樂器預設（折疊面板）**
  - 吉他 / 烏克麗麗 / 小提琴 / 大提琴 / 長笛 等
  - 選擇後直接顯示對應弦 / 音位參考

---

### 3-4. 設定頁（齒輪圖示 → 全螢幕彈出面板）

**子區塊：**

- 主題切換（淺色 / 深色 / 跟隨系統）
- 節拍器音效音量
- 調音器麥克風選擇（下拉，若有多個輸入裝置）
- 自動翻譜預設速度
- 關於（版本號、授權資訊）
- 檢查更新按鈕

## 5. 設計語言（摘要）

| 項目 | 說明 |
|------|------|
| 色彩系統 | 跟隨 Windows 11 Fluent UI 系統色 |
| 主色調 | 深藍 `#0078D4`（Fluent 藍）作為強調色 |
| 字體 | Segoe UI Variable（Windows 11 預設） |
| 圖示 | Fluent UI Emoji / Symbol集合 |
| 間距 | 8px 為基礎單位（8、16、24、32） |
| 圓角 | 4px（按鈕）、8px（卡片）、12px（面板） |
| 響應式 | 主內容區採用彈性佈局，縮放時保持比例 |
